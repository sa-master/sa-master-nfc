# Сценарій «кімната → прилади → вузол → траси» (прототип)

Статус: прототип, сторінка `tools/hidden/room.html` (noindex, без посилань з сайту).

## Рішення (від автора, 27.11)
- Вид зверху. Кімната задається розмірами (напр. 3000×2000 мм) + виступи / ніші / окремі колони.
- Прилади ставляться на стіни з прив'язкою «від кута №N, X мм» і висотою.
- Вузол або ввід труб (99 % — біля стіни) ставиться на стіну.
- Траси ХВП/ГВП будуються автоматично від вузла до приладів: **пара йде впритул**, на споживачі ХВП праворуч, ГВП ліворуч (обличчям до стіни).
- Відстань між осями не вводиться — рахується з діаметрів труб (півсума, типово 20 мм).
- Авто-траса — **чернетка (пунктир)**. У звіт йдуть лише ті, що натиснуто «Підтвердити як фактичні».
- Це змінює початкове ТЗ («не проєктуємо») — авто-пропозиція допустима лише з підтвердженням майстра.

## Обмеження прототипу
- Лише горизонтальний план: підйоми/спуски, висоти трас, ізоляція труб не враховані.
- Траси різних приладів, що йдуть спільним коридором, малюються поверх одна одної (відгалуження/трійники не моделюються).
- Крок пошуку 50 мм, координати округлено до 1 мм.
- Не перевірено на реальному телефоні; масштаб/панорамування відсутні (план вписується в екран).
