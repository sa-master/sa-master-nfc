# Результати перевірок

## Автоматичні (node tools/hidden/tests.js) — 16/16
Геометрія: довжина траси; прив'язка 0/90° і 45°; межі; вирівнювання; відстань до відрізка. Розміри: значення від лівого краю/низу; база «правий край»; ручні правки переживають перегенерацію; зміна розміру рухає ділянку без порушення прямих кутів; масштаб відображення не змінює ні дані, ні значення розмірів; підписи не накладаються; JSON туди-назад ідентичний; скасування/повтор повертають точні координати; перевірка звіту.

## У браузері (Playwright, емуляція iPhone 13, 27.11.2026)
- Три тапи → траса з точними координатами (450;0)-(450;1400)-(1700;1400); так само друга траса й точка.
- Поворот екрана (портрет↔ландшафт) і перезавантаження сторінки: координати всіх елементів ідентичні.
- Масштаб двома пальцями (k 0,117→0,350) і рух одним пальцем: координати не змінились.
- Вибір траси, числове введення X, скасування/повтор — коректно (після виправлення: порожня зміна не пише в історію).
- Розмір: зміна значення з 450 на 800 пересунула ділянку й її вузол; перемикання бази на «правий край» дало 2200 = 3000−800; приховання зберігається в `dimOverrides`.
- Режим 45°: (2000;300)→(2410;710) рівно по діагоналі. Зона з чотирьох точок. Перетягування вузла + скасування повернули точні координати.
- Лупа відображається при утриманні пальця.
