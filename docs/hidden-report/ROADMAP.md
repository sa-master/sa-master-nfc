# План

0. Аналіз і архітектура — готово (документи цього каталогу).
0.1 Тест автономного HTML на iPhone (Telegram, WhatsApp, «Файли») — файл надіслано, чекаємо результат.
1. Прототип редактора: окрема поверхня, розміри, точки/траси/зони, масштаб і рух, числове введення, автоматичні розміри, скасування/повтор, чернетка.
2. Геометрія: довільний полігональний контур, розгортки, імпорт підкладки, калібрування, переходи між поверхнями.
3. Бібліотека й персоналізація, групи, шаблони, фото.
4. Перевірка, PDF (вектор), інтерактивний звіт, автозбереження, офлайн.
5. Польові тести.

Приймання прототипу (Етап 1):
- поверхня 3,0 × 2,6 м і три траси за ≈1 хв;
- координати незмінні після масштабування, повороту телефона й перезавантаження (перевірка тестами та в браузері);
- розміри збігаються з ручним розрахунком; ручні правки розмірів переживають перегенерацію;
- скасування/повтор, чернетка відновлюється.
