# Звіт про приховані комунікації — вимоги

Статус: узгоджено з автором (27.11.2026). Повне ТЗ автора + уточнення нижче. Відкриті питання винесено окремо.

## Суть
Безкоштовний автономний інструмент SA-MASTER Tools для виконавчої документації: фактичне розташування прихованих комунікацій після монтажу, до закриття. Не CAD, не проєктування, не управління будівництвом.
Головний результат — креслення з розмірними прив'язками. Фото — додаткове.
Критерій: майстер зі смартфона, на об'єкті, швидко формує звіт для замовника.

## Затверджене (з ТЗ)
- Mobile First; iPhone/Android; жести (масштаб, рух двома пальцями); вертикаль/горизонталь; без реєстрації.
- Три сценарії: окрема поверхня; геометрія з нуля; імпорт підкладки (PDF/JPG/PNG, калібрування масштабу).
- Модель у мм, реальні координати, масштаб відображення не змінює координат. Редагування 2D, архітектура не забороняє 3D.
- Об'єкти: точка, траса, зона. Нанесення послідовними натисканнями (малювання пальцем без відриву виключено). Кути: 0/90 за замовчуванням, 45°, довільні.
- Групи паралельних комунікацій; переходи між поверхнями зі спільним id.
- Розмірні прив'язки від чистових поверхонь; режими деталізації (немає / мінімум / оптимум / повна), за замовчуванням оптимум.
- Режими відображення: схематичний і масштабний (без зміни геометрії).
- Бібліотека систем (вода, каналізація, опалення, електрика, кондиціонування/вентиляція), розширювана; монтажні групи; шаблони.
- Фото необов'язкові, нумерація збігається в PDF і на кресленні.
- Автоперевірка: критичні помилки блокують, попередження ні.
- PDF + інтерактивний звіт (лише перегляд). Підпис «Сформовано на sa-master.pro», без реклами і QR.
- Локальне збереження, автозбереження чернетки, IndexedDB. Без акаунтів, хмари, управління об'єктами.
- Попередження про перевірку перед свердлінням; без гарантій безпеки.
- Виключено: голос, глибина залягання, малювання від руки, обов'язковий план квартири, реєстрація, хмара, CAD.

## Уточнення автора від 27.11.2026
1. **Геометрія приміщень.** Довільний полігональний контур. Кожен прямий сегмент контуру — окрема вертикальна поверхня (довжина, висота, локальна система координат); розгортки формуються для будь-яких кутів між стінами. Криві й похилі поверхні поки не підтримуються.
2. **Розмірні прив'язки.** «Найближча стіна» не є єдиним правилом. Для кожної поверхні — стабільні базові орієнтири; автоматичні розміри від них; майстер може змінити базу. Ручні правки розмірних ліній зберігаються після повторного автоформування.
3. **Інтерактивний звіт.** Тестуємо автономний HTML. Проблеми на iPhone не причина відмовитися від звіту чи зупиняти розробку; спосіб передачі визначимо окремо.
4. **PDF.** Вектор + вбудований кириличний шрифт; текст виділяється й копіюється. Растрові лише фото та растрові підкладки.
5. **Автономність.** Бібліотеки й ресурси зберігаються локально на сайті, без залежності від CDN; передбачити офлайн-режим.
6. **Документація** до початку основного коду (ці файли).
7. **Приймання прототипу.** Окрім швидкості й зручності — математична точність геометрії, координат і прив'язок. Масштабування, поворот телефона, перезавантаження сторінки не змінюють координат. Однакова поведінка iOS/Android на технічному рівні не вимагається, лише однаково коректний сценарій.
