# Архітектура (запропоновано; SVG і загальна модель даних погоджені)

## Технології
- Редактор: SVG (чіткий масштаб, прості вибір і переміщення елементів, той самий малюнок йде в PDF та інтерактивний звіт). Canvas — лише для підкладок/фото. Жести (рух, масштаб двома пальцями) — через Pointer Events.
- Без збирача: звичайні ES-модулі в `tools/hidden/`, як і решта інструментів. Спільні модулі: `store.js`, `profile.js`, `tools.css`.
- Бібліотеки (jsPDF, pdf.js, шрифт) — локально в репозиторії, не з CDN.
- Працювати без інтернету після першого завантаження: окремий сервіс-воркер для цього інструмента (у `tools` зараз його немає).

## Модулі (розділені)
1. `geometry` — чисті функції: вектори, проєкції, довжини, перетини. Без DOM. Тестується автоматично.
2. `model` — сутності й схема даних, версії, id, операції (додати/змінити/скасувати), історія.
3. `library` — типи систем, кольори, символи, монтажні групи.
4. `dims` — автоматичні розмірні прив'язки.
5. `editor` — SVG-інтерфейс, жести, панелі.
6. `store` — IndexedDB: чернетки, фото окремо від креслення.
7. `pdf` — векторний рендер у PDF, незалежний від редактора.
8. `viewer` — інтерактивний звіт, лише перегляд.

## Модель даних (JSON)
- `schema: 1`, `id` (UUID) у кожної сутності, одиниці — мм (цілі числа).
- `Report { rooms[], surfaces[], systems[], elements[], links[], photos[], profile, createdAt }`
- `Room { id, name, contour: [point], height }`; `Surface { id, roomId?, kind: wall|floor|ceiling|free, name, width/height або contour, edgeIndex?, origin, baseline }`.
- Стіна кімнати = сегмент контуру: локальні координати (0,0) у лівому нижньому куті, якщо дивитись зсередини; будь-який кут між сусідніми стінами допускається.
- `Element { id, surfaceId, type: point|route|zone, systemId, pts[], props{} }`; групи — `Group { id, memberIds, gaps }`.
- `Link { id, ends: [{surfaceId, elementId, nodeIndex}] }` — перехід між поверхнями.
- Масштаб відображення — лише стан перегляду, не в координатах.

## Автоматичні розмірні прив'язки
- Для кожної поверхні є стабільні орієнтири: стіна — лівий край (початок сегмента) і чистова підлога; підлога/стеля — перші два ребра контуру; вільна поверхня — лівий нижній кут. Майстер може вибрати іншу базу для елемента чи поверхні.
- Розмір = `{ key: elementId+вузол+вісь, base, value }`. Значення рахується від бази, не зберігається.
- Ручні правки (прихований, перенесений, інша база, інше значення) зберігаються окремо за `key` і застосовуються поверх автоформування — тож повторне формування їх не стирає.
- Розкладка підписів: доріжки за межами креслення + перевірка перетину рамок підписів. Деталізація задає, які вузли отримують розмір.

## Інтерактивний звіт
- Один HTML-файл: дані JSON + малий переглядач (рух, масштаб, шари, фото). Тест на iPhone: окремий файл (див. STATUS).

## PDF
- Вектор: лінії й текст малюються безпосередньо в jsPDF, шрифт вбудований; фото й підкладки — растр. Існуючий `doc.js` (картинка) для цього не підходить.

## Ризики
- Передача HTML на iPhone (очікує тесту).
- Вбудований кириличний шрифт і розмір PDF.
- pdf.js для імпорту: потрібно покласти локально.
- Точність дотику на смартфоні: лупа й числове введення обов'язкові.
