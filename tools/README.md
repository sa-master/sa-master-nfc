# /tools — інструменти для майстрів

- `index.html` — список інструментів
- `floor.html` — калькулятор водяної теплої підлоги
- `hydro.html` — акт гідравлічних випробувань (перенесено з et.app)
- `hydraulics.html` — гідравлічний розрахунок квартири за ДБН В.2.5-64:2012 (таблиці А.5–А.9 у `shared/hydraulics.js`, тест: `node shared/hydraulics.test.js`)
- `diameters.html` — підбір діаметрів водопроводу (правила в `shared/diameters.js`, тест: `node shared/diameters.test.js`)
- `shared/` — спільні модулі:
  - `store.js` — локальне збереження (IndexedDB, схема v1)
  - `profile.js` — імʼя/компанія, телефон, логотип майстра
  - `doc.js` — PDF із підписом «Сформовано на sa-master.pro» (з посиланням) на кожній сторінці, «Поділитися»
  - `ui.js` — тост, список збережених документів, автозбереження
  - `floorcalc.js` — розрахункове ядро теплої підлоги (без DOM)
  - `tools.css` — спільний стиль

## Бібліотеки PDF
`doc.js` підтягує html2canvas і jsPDF з CDN (jsDelivr). Щоб не залежати від CDN, покладіть файли
`html2canvas.min.js` (1.4.1) і `jspdf.umd.min.js` (2.5.1) у `tools/vendor/`: вони підхоплюються першими.

## Додати новий діаметр труби
У `shared/floorcalc.js` додайте запис у масив `PIPES` (id, назва, рекомендована довжина контуру).

## Нормативні правила випробувань
`shared/hydrorules.js` — правила за ДБН окремо від інтерфейсу (допуск `null` = у нормі числового допуску немає). Перевірка: `node shared/hydrorules.test.js`. Перед запуском звірити актуальні редакції ДБН В.2.5-64:2012 і ДБН В.2.5-67:2013 (у реєстрі позначені «Архівний»).
